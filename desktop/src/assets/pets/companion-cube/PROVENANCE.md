# Companion Cube asset provenance

- Created for Jupiter with OpenAI image generation on 2026-07-16 and remastered on 2026-07-17.
- Animated and packaged with the Codex v2 pet atlas workflow.
- The built-in atlas is packaged at 768x1144 for a lighter, softly pixelated desktop presentation.
- Portal scenery was intentionally removed so the cube's own rigid-body motion carries each interaction.
- The Companion Cube character design is associated with Valve's Portal series; this repository does not claim ownership of that underlying design.
