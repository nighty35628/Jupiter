# Browser and Web
open_url opens an absolute http(s) URL in the default browser or Chrome when that tool is registered. It launches a URL; it does not itself inspect a page, click elements or operate the desktop.
Web research tools fetch/search remote content when enabled. Browser automation is a separate configured browser/MCP capability; the connected tool list is authoritative. Do not equate web_fetch, an opened URL, a browser integration and native Computer Use.
For actual browser actions use Agent and its available tools. Credentials, authentication and confirmation still apply. Explaining the browser feature does not require opening a page or researching Jupiter online.
